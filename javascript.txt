| Category          | Data Types                                               |
| ----------------- | -------------------------------------------------------- |
| **Primitive**     | Number, String, Boolean, Undefined, Null, BigInt, Symbol |

Variable Declarations:

| Keyword   | Scope    | Reassignment | Redeclaration | Hoisting Behavior             |
| --------- | -------- | ------------ | ------------- | ----------------------------- |
| **var**   | Function | ✅ Yes        | ✅ Yes      | Hoisted with *undefined*      |
| **let**   | Block    | ✅ Yes        | ❌ No       | Hoisted but *not initialized* |
| **const** | Block    | ❌ No         | ❌ No       | Hoisted but *not initialized* |


Hoisting: variable and function declarations are moved to the top of their scope before the code is executed.

    console.log(a); -> undefined
    var a = 10;

    let and const

    console.log(b); // ❌ ReferenceError
    let b = 20;


| Keyword      | Hoisted? | Default Value   | Can Access Before Declaration? |
| ------------ | -------- | --------------- |------------------------------- |
| **var**      | ✅ Yes  | `undefined`     | ✅ Yes (but value is undefined) |
| **let**      | ✅ Yes  | *uninitialized* | ❌ No (TDZ error)               |
| **const**    | ✅ Yes  | *uninitialized* | ❌ No (TDZ error)               |
| **function** | ✅ Yes  | Function body   | ✅ Yes                          |

Errors: These are the programmatical mistakes that are created by the developers.

Types of Errors: 
    1. Syntax Errors
    2. Type Errors
    3. ReferenceErrors
    4. URI(Uniform Resource Identifier) Errors

Exceptions comes inside errors in JavaScript

try Block: The try block is used to test a block of code for errors.
catch Block: The catch block is used to handle the error.
finally Block: The finally block is used to execute code, regardless of the result of the try and catch blocks.


Hoisting: It is a Behavior of JavaScript where it moves the declaration of variables, functions and classes to the top of their scope during compilation before the code is executed.

    Two phases of Hoisting:
        1. Memory phase (Declaration phase)
        2. Execution phase (Initialization phase)

    TDZ: Temporal Dead Zone - The period of time during which a variable is not accessible. (The code between error and variable declaration is TDZ)

Debugging: Debugging is the process of finding and fixing errors in a program.
